# 응급레이더 입구 페이지

구급대원이 버튼 몇 번으로 지금 받아 줄 응급실을 찾는 웹 앱 **응급레이더**의 설치용 입구 페이지입니다.

- 주소: https://yeo-sg.github.io/emsradar/
- 이 페이지는 앱 이름·아이콘·설치 정보만 담고, 실제 앱(Streamlit)을 화면 가득 띄웁니다.
- 휴대폰에서는 "홈 화면에 추가", PC에서는 브라우저의 "설치"를 누르면 "응급레이더" 이름과 아이콘으로 설치됩니다.
- 주소 뒤에 `?demo=1`을 붙이면 예시 환자로 바로 검색하는 시연 화면이 열립니다.

데이터, 인증키, 추천 코드는 이 저장소에 없습니다.
